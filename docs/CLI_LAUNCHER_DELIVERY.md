# 命令行 Agent 启动器交付说明

本版已安装到 `E:/AI进度插件`，桌面文件夹快捷方式不变。

## 如何使用

双击 `launch_agent.cmd`，选择 Agent，然后输入工作目录。真实工具仍使用自己的终端和登录配置。已经打开 HUD 时，可右键选择“启动命令行 Agent”。

没有 AI 也能检查真实进程通路：在菜单输入 s。它是标记为“非 AI”的样例程序，会由包装器创建真实子进程并接收其输出。

详细说明见 [CLI_AGENT_LAUNCHER.md](../docs/CLI_AGENT_LAUNCHER.md)。

## 已实现

- 通用命令行程序启动，PATH 发现和自定义配置。
- 交互式终端模式和输出采集模式。
- 运行、等待、程序上报进度、退出、失败和停止。
- 只终止本次启动的进程组，拒绝不支持的暂停/继续。
- Hub 重启后，运行中的包装器重新上报完整状态。
- 默认不向 HUD 转发原始输出，不保存模型密钥。

## 验证范围

25 个包装器专项测试，覆盖真实进程、HTTP 控制、进程树、标准输入、中文与空格路径、Windows 批处理、错误退出、Hub 重连、协议校验。

本机真实 Codex CLI 已通过包装器运行 --version。PATH 中原有 codex.cmd 指向失效旧路径，因此仅在 E 盘安装目录的 config/agents.local.json 中配置了当前有效路径，没有修改全局启动器。机器专用配置不进入源码包。

尚未发起真实模型任务，也没有验证所有厂商的交互终端。terminal 模式只表示进程仍在，不能据此判断模型正在思考或等待输入。capture 模式使用管道；完整终端应用请选 terminal。

步骤进度来自显式事件，标为“已上报”；普通退出码零只表示进程正常结束，不当作任务验证成功。暂停不可用；停止属于结束进程，不是回滚。
