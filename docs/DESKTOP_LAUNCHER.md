# 桌面应用启动器

双击 `launch_agent.cmd` 或 `launch_desktop.cmd`，打开图形启动窗口。此入口不会启动 Codex CLI；旧的终端入口保留为 `launch_cli.cmd`。

## 添加自己的 Agent

1. 点“添加程序路径”，选择桌面程序的 `.exe` 或 `.lnk` 快捷方式，也可以粘贴路径。
2. 选择接入类型：Codex / ChatGPT（工作状态）或其他应用（仅启动）。
3. 点启动。路径自动保存在本插件 `.state/uah/desktop-apps.json`；下次从上面的列表选即可。不要选择安装目录内捆绑的命令行程序。

默认“自动检测 ChatGPT / Codex”通过 Windows 开始菜单识别安装的桌面应用。自定义路径只解决启动，不代表该程序支持 UAH 反馈；不能把其他程序标成 Codex 来获得状态。

## Codex / ChatGPT 工作状态

选择工作目录后，启动器在该目录的 `.codex/hooks.json` 添加 UAH 桌面钩子；保留其他钩子，并首次备份原文件到 `hooks.before-uah-desktop.json`。反馈通道位于同一目录的 `.uah/uah-feedback-desktop`。这些是本机配置，不建议随项目提交到 Git。

打开软件后，在软件中使用同一工作目录，并审核信任 UAH 项目钩子。可在钩子设置中查看；如当前聊天未加载新的项目配置，请重新打开该目录的聊天。没有信任或目录不一致时，UAH 无法获得事件。普通 ChatGPT 云端聊天不一定使用本地 Codex 项目钩子；当前状态接入针对桌面中的本地 Codex Agent 工作流。

状态包括开始、公开阶段摘要、工具执行、等待确认和本轮结束。会话分别显示在 HUD 的 Agent 选择中；不会读取隐藏推理。公开会话文件的格式和写入时机可能随版本变化，因此摘要可能延迟。

关闭 HUD 会结束这次状态监听，保留桌面应用。监听关闭后，项目钩子自动安静返回；不会不停累积事件。停止、暂停任务请在桌面应用中操作，UAH 不终止整个桌面应用。

## 测试

先用普通问题或小型文件任务，观察桌面应用是否出现公开阶段说明，以及 UAH 的对应记录。其他应用选择“仅启动”，只验证打开了所选程序。自动回归测试：`run_uah.cmd uah.tests.verify_progress`，包括项目配置保留、幂等安装、完整 Windows 钩子命令、会话隔离与关闭后的静默行为。自动测试不代表已验证所有版本的桌面应用或普通云端聊天。

工作状态会保留 AI 本轮公开报告的阶段说明，工具动作单独显示在当前步骤中，例如正在搜索资料、正在阅读网页资料。插件不读取隐藏推理，也不会补造未上报的阶段。新一轮对话会清空上一轮阶段。
