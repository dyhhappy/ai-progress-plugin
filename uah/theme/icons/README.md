# 图标资源（uah/theme/icons）

UAH 的图标**用字形（glyph）而不是图片**，理由：

* 零依赖、零加载失败面；
* 随 DPI 与字体自动缩放，任何缩放下都不糊（位图图标在 150%/200% 下必然发虚）；
* 与 `tokens.py` 的颜色 token 直接联动（悬停/危险态换色，不需要两套图）。

字形表定义在 `uah/theme/tokens.py::ICONS`（**唯一来源**，宿主不得自行写死）：

| 语义 | 字形 | 位置（对应 UI 概念图） |
|---|---|---|
| 暂停 / 继续 | `❙❙` / `▶` | Compact 右上操作簇、Expanded 底部（图 02 / 06） |
| 展开 / 收起 | `⤢` / `⤡` | Compact 右上、Mini 右侧（图 04 / 05） |
| 停止 | `■` | Compact 右上（红色，图 02） |
| 设置 | `⚙` | 展开面板「设置」页 |
| 关闭 | `✕` | 展开面板右上 / 右键菜单 |
| 状态灯 | `○` / `●` | 品牌区（所有形态） |

每个图标按钮同时带**中文悬停提示**（`tokens.ICON_HINTS`），在活动行短暂显示
（例如「暂停任务」「展开面板」）——既保留概念图的图标排版，又满足中文可读。

## 如果以后要换成矢量/位图图标

1. 把 svg/png 放这里，并在 `uah/theme/tokens.py` 增加 `ICON_ASSETS` 映射；
2. 宿主的 `_icon_button()` 改成"有资源用资源、无资源回退字形"；
3. 不要在宿主里硬编码图标名或颜色。
